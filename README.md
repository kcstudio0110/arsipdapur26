# Arsip Dapur 26

Official repository for Arsip Dapur 26.

## Overview

Arsip Dapur 26 is a modern Indonesian food brand focused on preserving authentic family recipes through convenient ready-to-eat products.

- React
- TypeScript
- Tailwind CSS

### Backend

- FastAPI _(planned)_
